# Himanshu Trivedi — Portfolio

Next.js portfolio built with TypeScript, Tailwind CSS v4, and Lucide icons. The site is configured for static export and GitHub Pages.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static site is generated in `out/`. GitHub Actions deploys the `main` branch to GitHub Pages.

## Deployment note

The redesign is being developed on `portfolio-v2`. The existing `main` branch and currently published portfolio are intentionally left unchanged until the new version is reviewed and ready to replace them.
